
# Customer Analysis - EDA (Exploratory Data Analysis)

This repository contains the **Exploratory Data Analysis (EDA)** on customer data, where we analyze various aspects such as age distribution across marital status groups. The main goal of this project is to uncover meaningful insights about customer behavior using visualization techniques.

## Project Overview

In this project, I performed a thorough **Exploratory Data Analysis (EDA)** on a customer dataset, focusing on the following:
- Import libraries
- load the dataset
- Inicial data exploration
- fill the null values
- Analyzing customer age across different marital status groups.
- Understanding trends and patterns in the data.
- Visualizing the results using boxplots and other statistical plots.

### Key Insights:
- **Age Distribution by Marital Status:** A boxplot analysis of the **age distribution** across various **marital status** categories.
- **Marital Status Trends:** Insights into how marital status groups compare in terms of age distribution.

## Files Included:
- **Customer_EDA.ipynb:** Jupyter Notebook containing the EDA steps, visualizations, and findings.


## Visualizations:
- **Boxplot of Age Distribution by Marital Status:** Shows how age varies across different marital status groups.
